# 光纤行业获客助手

一个**本地运行**的获客工具，专为光纤行业（光缆、光纤收发器、熔接施工、FTTH、机房改造、弱电工程等）设计，包含三大能力：

1. **线索采集**：Excel/CSV 批量导入（自动去重）、网页采集（从目录页提取公司名和电话）、手动录入。
2. **客户管理（轻量 CRM）**：客户类型、跟进状态、标签、跟进备注、下次跟进提醒、搜索筛选、一键导出。
3. **主动触达**：内置 5 套光纤行业邮件模板 + 3 套短信模板、AI 智能生成营销文案、SMTP 邮件群发（自动个性化）、短信名单整理导出。

## 怎么启动

双击 **`启动工具.bat`**，等待窗口提示后，在浏览器打开：

```
http://127.0.0.1:8017
```

> 浏览器页面不要关闭，工具关闭时直接关掉黑色命令行窗口即可。所有数据保存在本机 `data/app.db`，不需要联网。

## 快速上手

1. **添加客户**：进入“线索采集”页 → 下载导入模板，填好后上传；或直接“手动录入”。
2. **跟进管理**：进入“客户线索”页，搜索、筛选、点击公司名查看详情，添加跟进备注、设置下次跟进日期。
3. **发邮件**：进入“主动触达”页 → 选择收件人 → 选一套行业模板 → 点发送。发信前先到“设置”里配置发信邮箱。
4. **AI 文案**：在“设置”里填入 OpenAI API Key 后，“文案生成”页即可让 AI 帮你写开发信、短信、朋友圈文案。

## 邮件配置（SMTP）

发信邮箱需要支持 SMTP：

- **QQ 邮箱**：设置 → 账户 → 开启“POP3/SMTP 服务”，生成授权码；服务器 `smtp.qq.com`，端口 465（SSL）。
- **163 邮箱**：设置 → 客户端授权密码；服务器 `smtp.163.com`，端口 465（SSL）。
- **企业邮/阿里邮箱**：问一下公司 IT，一般也是 `smtp.公司域名` + 465/587。

在“设置”里填好后点“保存”，再点“发送测试邮件”确认能用。

## 短信说明

短信需要通过运营商短信网关（如阿里云短信）发送，需要营业执照和签名审核。当前版本提供：

- 短信模板（光纤行业专用）；
- 一键复制号码列表 / 短信内容；
- 导出号码文本文件，方便粘贴到手机短信 App 或第三方群发平台。

## 网页采集说明

“网页采集”会从你粘贴的网址中提取电话号码并匹配附近的公司名称。请只采集你有权使用的公开信息，遵守网站条款和相关法律法规；部分网站有验证码、登录墙或反爬措施，采集不到时建议改用 Excel 导入。

## 数据与备份

- 数据文件：`data/app.db`（SQLite）。
- 备份：直接复制 `data` 文件夹即可。
- 重置：停止工具后删除 `data/app.db` 再启动即为全新数据库（不可恢复，请先备份）。

## 技术说明

- Python 标准库（HTTP 服务）+ SQLite，无第三方依赖（Excel 用 openpyxl、网页解析用 lxml，随附带好）。
- 默认只在本机 `127.0.0.1:8017` 提供服务，其他设备无法访问。
